# BankDash. - Financial & Banking Admin Dashboard

BankDash is a modern, responsive financial dashboard UI kit built with React 19, Tailwind CSS, Recharts, Lucide Icons, and Framer Motion.

## Features

- **Dashboard**: Account balances, recent transactions, weekly activity bar chart, expense statistics pie chart, quick money transfer, and balance history spline chart.
- **Transactions**: Filterable transaction logs, search, pagination, and expense analytics.
- **Accounts**: Multi-bank account tracking, debit/credit analytics, and account management.
- **Investments**: Investment portfolios, trending stocks, ROI calculations, and asset distribution.
- **Credit Cards**: Interactive card previews, card settings, block/unblock controls, and new card application form.
- **Loans**: Active loans overview, repayment calculator, and loan application modal.
- **Services**: Financial service directory, bank utilities, and service management.
- **Privileges & Settings**: Profile customization, security settings, two-factor authentication, and notifications.

## Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS
- **Charts**: Recharts
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **HTTP Client**: Axios
